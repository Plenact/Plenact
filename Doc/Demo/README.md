## For Contributors

- Use concise filenames that identify the sequence and subject.
- Prefer demonstrations with realistic, non-sensitive sample data.
- Avoid recording personal notifications, account information, or private board content.
- Move superseded recordings to `.Archived/` instead of presenting them as current.
- Document any feature shown in a demo that is still proposed or incomplete.

Large media files affect repository size. Add new recordings deliberately and keep only useful development or product-reference material.
