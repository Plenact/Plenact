# Product Demos

This directory contains video demonstrations of Plenact's user experience at particular points in development.

## Current Material

- `3 Begin - Plenact.mov`: current tracked walkthrough recording.
- `.Archived/`: older demonstrations retained for historical reference and excluded from active documentation coverage.

## For Viewers

Videos are snapshots, not promises of current behavior. Compare them with the app and the status statements in [`../Today-View-UI.md`](../Today-View-UI.md) and [`../Board-and-Scheduled-Views.md`](../Board-and-Scheduled-Views.md).

## For Contributors

- Use concise filenames that identify the sequence and subject.
- Prefer demonstrations with realistic, non-sensitive sample data.
- Avoid recording personal notifications, account information, or private board content.
- Move superseded recordings to `.Archived/` instead of presenting them as current.
- Document any feature shown in a demo that is still proposed or incomplete.

Large media files affect repository size. Add new recordings deliberately and keep only useful development or product-reference material.
