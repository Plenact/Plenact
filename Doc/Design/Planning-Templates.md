# Day and Week Templates

Open Library → Templates (or + → Templates → Browse all templates). Manage routines here alongside the existing List templates. Jmr is the default Week routine, with distinct timed weekdays and weekends. Work Week starts from the original demo week; Vacation Day is an editable Day example. A separate Example Week can be previewed and saved as a template. Existing installations retain all planned weeks. A fresh workspace starts from Jmr; subsequent unsaved weeks use the selected default, once, on creation. Empty week disables automatic routines.

Save a selected planned day or week, edit/duplicate/delete it, preview a destination, and apply independent copies. Add retains existing work. Replace explicitly confirms replacement of active target day/dated-week items; archived content and undated destination lists survive. Captured archives/activity are excluded, completion resets, dates shift relative to the source day or by weekday/week offset, and checklist links within the captured content point to fresh copies. External card links become plain checklist actions.

Preview and editing do not mutate plans. Applying uses a target baseline, a final saved-calendar comparison and checked journaled Week/Board writes before publishing. Template store saves compare a baseline, validate unique identities and the default kind, and preserve unreadable data. Drawing/image/audio files stay protected while referenced by templates, and full workspace backup/restore includes the store and files. Templates are local to the device.

Validation covers seed/store round trips and conflicts, corrupt-byte retention, independent identities and completion reset, retained media, internal links, Sunday/Monday starts, daylight-saving dates, Day replacement and archives/bookmarks, default rollover once/disabled, read-only phone/tablet presentation, transaction recovery and workspace backup.

## Jmr default routine

The Jmr template uses the user's 28 weekly time blocks, interpreting weekday Work as 7 a.m.–5 p.m. and Gym as 5–6 p.m.; weekend noon stops remain p.m. Gym includes the user's meditation/walking/massage alternatives. Date-and-time fields preserve weekday alignment and wall-clock times through week-start changes and daylight-saving transitions. Older template libraries gain the preset and select it once; their prior templates and all scheduled weeks remain unchanged. Subsequent default changes or deletion remain authoritative after explicit saving.
