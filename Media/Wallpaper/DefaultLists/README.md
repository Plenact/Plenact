# Default List background originals

Full-resolution JPEG downloads from Pexels, archived on October 16, 2026 for the three default Plenact Lists. Files are the downloaded bytes, without local cropping, resizing, retouching, or recompression. These are the original-size Pexels downloads, not camera RAW originals.

Each List folder contains its photo and an `Original Source.webloc` shortcut that opens the source page. `sources.json` records photographer credits, source and download URLs, byte sizes, and SHA-256 checksums. The Scheduled download filename names Ian Panelo; the source page displays the photographer as Nothing Ahead.

## Selected On the Table background

[Notebook, Calendar and a Black Mug on a Wooden Table](https://www.pexels.com/photo/notebook-calendar-and-a-black-mug-on-a-wooden-table-4985338/) by Anna Tarazevich is the selected default.
