# Product Discovery Work

This directory contains working reference material used to understand the planning method that Plenact is intended to support

## Purpose

The material here records real workflow shapes, visual references, and exports from tools that temporarily served Plenact's planning needs. It informs product decisions but is not loaded by the application at runtime

- [`WorkByDay/`](WorkByDay/README.md): references grouped by the day they were collected or reviewed

## For Developers and Product Reviewers

Use these artifacts to identify user needs, not as a schema to copy mechanically. Existing Trello content may be intentionally messy because one external board was carrying scheduling, routines, tasks, ideas, and open work at once

Do not add import behavior, third-party API access, or synchronization based solely on a reference export. Those capabilities require explicit scope, privacy review, model design, and migration/testing plans

## Privacy

Before committing new work material, remove credentials, private URLs, personal health information, customer information, notifications, and unrelated account data. Prefer sanitized examples where the same product insight can be preserved
