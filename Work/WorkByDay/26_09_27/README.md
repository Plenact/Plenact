# Weekly Planning Reference: September 27, 2026

This directory captures the Trello workflow that helped establish Plenact's initial Today, Board, and scheduling direction.

## Contents

- `Trello Personal Plenact Board.png`: wide screenshot of the weekly planning board.
- `4-📆-weekly-planning-board-ww39.json`: Trello board export used to inspect list and card structure.

## What This Reference Shows

- Weekday lists act as day plans.
- Card order represents the intended sequence of routines and work.
- Divider cards separate portions of a day.
- Some card titles contain human-entered time ranges.
- An “Opens” list holds work outside a specific day plan.

The export also reflects the constraints of using Trello as a placeholder. Its content should not be treated as a polished Plenact information architecture or imported into user storage without a separately designed import workflow.

## Current App Relationship

Today can select and open an existing Plenact list, and Board remains the editable source of truth. A Scheduled view and structured event times are proposed but not implemented. Time-like card titles remain ordinary text; they are not validated calendar events.
