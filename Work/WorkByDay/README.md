# Work by Day

This directory groups product-discovery artifacts by collection date. Date folders are historical work snapshots, not application storage and not a required naming convention for Plenact's future schedule model.

## Organization

Folders use a compact date label such as `26_09_27`. Each dated directory should explain where its material came from, what product question it informs, and whether it contains sanitized or potentially sensitive reference data.

## Use in Product Design

Day-based references can reveal recurring patterns such as weekday lists, manually ordered routines, divider rows, and separate open-work lists. They should inform Today, Board, and proposed Scheduled experiences without forcing Trello's structure or text-based time conventions into Plenact's domain model.

See [`../../Doc/Board-and-Scheduled-Views.md`](../../Doc/Board-and-Scheduled-Views.md) for the current architectural interpretation.
